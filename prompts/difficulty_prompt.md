
# 난이도별 변형 문제 생성 규칙

## 공통 규칙

- 사용자가 입력한 학습 목표를 유지한다.
- 기존 JSON 데이터 구조를 변경하지 않는다.
- 파일명과 파일 내용을 다양하게 생성한다.
- 실행 가능한 순서로 파일 작업을 구성한다.
- 실제 작업 시각과 증거 기록을 임의로 생성하지 않는다.
- 문제에 정답을 직접 노출하지 않는다.
- 지원하는 파일 작업만 사용한다.

## 초급 (easy)

- 파일 생성 작업: 3개
- 전체 작업 수: 4~5개
- 실습 문제 수: 2개
- 무관한 정상 작업: 0개
- 단순한 파일 작업을 중심으로 구성한다.

## 중급 (medium)

- 파일 생성 작업: 5개
- 전체 작업 수: 7~10개
- 실습 문제 수: 3개
- 무관한 정상 작업: 1~2개
- 복사, 이동, 이름 변경 등을 일부 포함한다.

## 고급 (hard)

- 파일 생성 작업: 7개
- 전체 작업 수: 11~15개
- 실습 문제 수: 4개
- 무관한 정상 작업: 3~4개
- 다양한 파일 작업을 복합적으로 구성한다.
- 정상 작업 사이에 분석 대상 작업을 배치한다.

## 변형 문제 생성 규칙

- 동일한 학습 목표라도 파일명과 내용을 다양하게 구성한다.
- 작업 간 의존성을 유지하면서 작업 순서를 변경한다.
- 난이도가 높을수록 분석할 기록의 양을 늘린다.
- 모든 문제는 실제 작업 ID를 참조한다.
- 핵심 학습 목표와 관련 없는 문제는 출제하지 않는다.
- 요청받은 난이도의 수치 조건을 반드시 충족한다.

## 출력 규칙

- 기존 사건 설계 JSON 규격을 유지한다.
- 난이도 관련 필드를 임의로 추가하지 않는다.
- 하나의 JSON 객체만 반환한다.
